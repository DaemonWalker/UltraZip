# UltraZip — Windows 压缩与解压工具

UltraZip 是一个简单易用的 Windows 桌面压缩与解压工具，以官方 7-Zip 处理常见格式，并内置特殊 ZIP / WinZip-AES 解压器，支持创建压缩包、分卷包、加密包和伪装文件（如视频文件里藏压缩包）的解压。

## 功能

- **压缩创建**：7Z / ZIP / TAR / GZ / BZ2 / XZ / TGZ / TBZ2 / TXZ，支持压缩级别、AES 加密、7Z 文件名加密和 7Z/ZIP 分卷；创建后可自动校验，失败或取消会清理暂存文件
- **多格式解压**：7z / ZIP / RAR / GZip / TAR / BZip2 / XZ / ISO / CAB / WIM / ZSTD / LZ4；魔数、EOCD/ZIP64 与 7z 三层识别，支持前置 ZIP 和 SFX 自解压包
- **分卷包**：`.7z.001`、`.part1.rar`、老式 `.r00`、`.z01` 等分卷自动归并，只需拖入任意一卷；缺卷时给出明确提示
- **加密包解压**：内置密码库，遇到加密压缩包时自动依次尝试库中密码；全部未命中再弹窗询问，可勾选“成功后保存到密码库”
- **特殊 ZIP 兼容**：自动修正视频等前置数据造成的偏移，支持 WinZip-AES（AES-128/192/256、AE-1/AE-2），自动尝试 UTF-8、GBK 等密码编码，并逐条目校验 HMAC/CRC
- **密码管理器**：密码的增删改查，按使用频率智能排序
- **伪装文件扫描**：扫描视频/图片等文件内部隐藏的压缩包（按魔数定位偏移），列出后一键解压
- **归档浏览**：目录树 + 明细/列表视图，查看大小、压缩后大小、时间、CRC 和方法，支持过滤、勾选条目选择性解压、双击调用默认程序查看
- **视图与图像预览**：F6 返回启动画面、F7 切换目录树、F8 查看 ZIP 注释；支持工具栏/状态栏/置顶、列显隐与排序、布局记忆，以及带密码流程的右侧图片预览（单条最大 30 MB）
- **Windows 集成**：可选注册级联右键菜单和“打开方式”关联，支持命令行、静默任务和单实例转发，不强制修改默认应用
- 拖放操作、压缩/解压进度显示、中文界面

## 运行

环境要求：Windows + .NET 8 桌面运行时（或本机安装 .NET SDK）。

```bash
# 源码运行（需要 .NET SDK）
dotnet run --project UltraZip

# 或构建后直接运行
dotnet build UltraZip.sln
UltraZip\bin\Debug\net8.0-windows\UltraZip.exe
```

## 使用方法

1. **新建压缩包**：点击“新建压缩包”，添加或拖入文件/文件夹，选择格式、级别、密码、分卷和输出路径后开始压缩。也可直接拖入非压缩包或文件夹，按提示进入创建窗口。GZ/BZ2/XZ 仅接受单文件，多文件请选 TGZ/TBZ2/TXZ。
2. **解压压缩包**：把压缩包文件拖进窗口（或点“打开压缩包”），选择“解压到”目录后点“解压全部”。“解压并删除压缩文件”会在完整解压成功后永久删除原压缩包；分卷包会删除全部已识别分卷，解压失败或取消不会删除。
3. **分卷包**：把所有分卷放在同一目录，拖入任意一卷即可，程序会自动找到首卷；缺卷会提示缺哪一卷。创建的 ZIP 分卷使用 `.zip.001/.002` 命名。
4. **加密包**：直接解压即可——程序会先自动尝试密码库中的所有密码；都失败时会弹出密码对话框，可手动输入或从库中选择，勾选“解压成功后保存到密码库”下次就不用再输。
5. **密码管理器**：主窗口“密码管理器”按钮进入，可添加、编辑（直接在表格中改）、删除密码，并查看每条密码的命中次数。
6. **伪装文件**（如 xxx.mp4 实际内含压缩包）：拖入该文件后点“扫描伪装压缩包”，程序会列出扫描到的压缩包格式和偏移位置；选中后程序先尝试直接解压原文件，失败时会询问是否从偏移处切出数据副本再解压。
7. **嵌套特殊 ZIP**：像 `1.zip` 这种“前置视频 + UTF-8 AES 外层 + GBK AES 内层”的文件，直接拖入并输入同一密码即可解开外层；得到 `1635.zip` 后再次拖入解压，程序会自动识别内层所需的密码编码。
8. **右键菜单与关联**：在主窗口“集成设置”中选择注册或移除。注册后，文件和文件夹右键可用“添加到压缩文件…”，压缩包的 UltraZip 级联菜单提供打开、解压、解压到此处并删除压缩文件和测试。Windows 11 的右键命令位于“显示更多选项”；程序不会修改现有默认应用。
9. **归档浏览与部分解压**：打开压缩包后，在左侧选择目录、右侧勾选条目，点击“解压选中”即可只解所需内容；双击文件会解到临时目录并调用系统默认程序打开，临时目录在退出 UltraZip 时清理。

## 命令行

```bash
UltraZip.exe --open "a.zip"
UltraZip.exe --add "文件或文件夹"
UltraZip.exe --extract-here --quiet "a.zip"
UltraZip.exe --extract-here-delete --quiet "a.zip"
UltraZip.exe --extract-to "D:\output" "a.zip"
UltraZip.exe --extract-to-dialog "a.zip"
UltraZip.exe --test "a.zip"
UltraZip.exe --test --password "密码" "a.zip"
UltraZip.exe --register
UltraZip.exe --register-all-users
UltraZip.exe --unregister
```

重复启动会把命令转发给已有实例；`--quiet` 不显示主窗口，但仍显示结果提示。`--register` 写当前用户，`--register-all-users` 需要 UAC，`--unregister` 清理当前用户注册。

## 数据存储与安全提示

> **注意：密码库以明文 JSON 保存在 `%APPDATA%\UltraZip\passwords.json`（即 `C:\Users\<用户名>\AppData\Roaming\UltraZip\passwords.json`），任何能访问该文件的程序都能读到你的密码。请勿在库中保存重要账户密码，并注意保护该文件。**

删除该文件即可清空密码库。窗口尺寸、目录树/预览宽度、列布局和视图开关保存在 `%APPDATA%\UltraZip\settings.json`，不包含压缩包密码。伪装文件切出的临时副本、图片预览和压缩创建的暂存文件优先放在 `%TEMP%\UltraZip\`，用后或退出时自动删除；系统临时目录权限不足时，暂存目录会回退到源文件或输出目录，同样在完成、失败或取消后清理。
